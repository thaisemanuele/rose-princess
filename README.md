# Rose Princess

A dark VS Code theme with castle-night plum, a golden ballgown, an enchanted rose and old library parchment.

## Palette

<!-- palette:start -->
| Role | Color |
| --- | --- |
| Sidebar and panels | `#151015` |
| Editor background | `#1d171c` |
| Menus, inputs and widgets | `#2b2229` |
| UI accent (selection, buttons, badges) | `#c2415f` |
| Text | `#e6dfe3` |
| Comments | `#8e9c93` |
| Keywords, operators, tags | `#f0b85b` |
| Functions, keys, attributes | `#f7c6cf` |
| Strings | `#9cc7ae` |
| Types, numbers, cursor | `#f5dfc0` |
| Rare accent (this, regex, enum members) | `#f2708e` |
<!-- palette:end -->

## Install

Search for **Rose Princess** in the Extensions view, or run:

```
code --install-extension thaisemanuele.rose-princess
```
